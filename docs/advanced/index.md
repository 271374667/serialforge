# 进阶指南

> 把这一章当成你的上位机瑞士军刀：按需取用，不用死记硬背。

入门教程能帮你快速把一条简单的 PING/PONG 指令跑通。但是在实际项目中，硬件设备总会提出各种奇葩的要求：

- “我这台设备一次性吐三行传感器数据，怎么接？”
- “发完启动命令后，设备像水龙头一样不停灌波形数据过来，怎么画折线图？”
- “用户点了第 10 行的按钮，回包时我怎么知道更新界面的哪一行？”
- “有的老旧传感器根本不发换行符，吐完数据就沉默，怎么判断一句话说完了？”
- “万一现场工人手欠把 USB 线碰掉了，怎么自动重连？”

这一章把上位机开发里的这些常见坑逐个拆开，给你现成的解决方案。

## 推荐阅读次序

如果你正在规划一个新项目的上位机架构，建议按下面的顺序浏览：

1. **[声明与响应模式](declarations.md)**：学会如何把硬件协议文档翻译成声明式对象，强烈推荐看看里面的 `@dataclass` 自动解析，能省去大量写字符串切分的时间。
2. **[发送、回调与取消](sending.md)**：理解主线程闭包、`context` 上下文穿透传参，以及任务超时的边界规则。
3. **[扫描与连接](scan-connect.md)**：掌握 VID/PID 过滤机制，避免扫端口时因为无辜的蓝牙设备卡死几秒钟。
4. **其余章节按需查阅**：什么时候协议遇到特殊定界、或者需要自动重连了，再翻对应的说明。

每一页我们都尽可能附上贴近实际生产的代码片段。遇到不习惯的术语，随时可以跳到 [术语表](../appendix/glossary.md) 看看通俗解释。
