## 说明

- **单一激活**：「激活中」永远最多一行；激活新任务时旧的自动退回「排队中」。
- **完成即出表**：任务归档（完成 / 废弃）后**必须**从本表删除该行，历史由 `todo/_archive/` 留存。
- **排序**：优先级 `高 > 中 > 低`，同优先级按编号升序（先建的先做）。
- **改优先级**：`taskmgr.py priority <编号> 高|中|低`（同步改任务文档文首的 `优先级`）。
- **队列为空**：两个表都空 = 真的没有排队任务，去问用户，不要自己从代码里猜一个出来。
