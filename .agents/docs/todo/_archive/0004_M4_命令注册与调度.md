# 0004_M4 命令注册与调度

> 状态: 已完成  |  创建: 2026-10-08  |  完成: 2026-10-08
> 优先级: 高  |  关联 checkpoint: checkpoint/0005_M4 命令注册与调度.md

## 背景

M3 的传输、假后端与诊断组件已完成。M4 按设计文档第 5、8、13、14 节实现命令注册、文本匹配、响应解析和调度；真实设备 COM11 可发送 `Version\r\n`，115200 波特率下回复 `Software version <版本号>`，回复无结束符。设备发现仍属 M6。

## 目标（验收标准）
- [x] `CommandRegistry` 保留声明对象身份，支持运行时注册/注销、不可变快照、重复与模板骨架冲突检测、文本精确及模板匹配。
- [x] `CommandDispatcher` 支持 `NO_REPLY`、`SINGLE`、`MULTI`、`STREAM` 和 `EXCLUSIVE`、`TAGGED`；结果及事件携带原始声明对象。
- [x] 实现参数注入防护、数据类/数值/字典解析、设备错误、回显跳过、主动上报和原始文本发送。
- [x] 实现优先级、队列上限、取消、超时、自适应 RTO、迟到帧隔离和恰好一次完成；STREAM 背压与日志 TX 标注符合设计。
- [x] 无硬件测试覆盖设计文档 M4 所列任务和关键组合；以不同版本号的 `Software version <版本号>` 测试真实设备声明，且默认测试不打开 COM11。
- [x] 阶段 CI、架构与文档检查通过；Windows 真机和未验证项据实记录，汇报后等待确认进入 M5。

## 阻塞 / 依赖
