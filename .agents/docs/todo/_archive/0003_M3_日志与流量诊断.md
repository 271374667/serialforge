# 0003_M3 日志与流量诊断

> 状态: 已完成  |  创建: 2026-10-01  |  完成: 2026-10-01
> 优先级: 高  |  关联 checkpoint: checkpoint/0004_M3_日志与流量诊断.md

## 背景
M2 已完成传输层和无硬件后端；M3 落地可复用的流量记录与按连接日志文件能力，供后续 M4/M5 收发调度和连接生命周期接入。实现遵循设计文档第 9 节与 T-06、T-20、T-21、T-32、T-51。

## 目标（验收标准）
- [x] `TrafficLogger` 接收 TX/RX 流量，生成毫秒时间戳、十六进制和可读文本；保留有界环形缓冲并发出 `traffic_logged(TrafficRecord)`。
- [x] 所有日志仅使用 loguru DEBUG；默认禁用时无输出；启用后采用延迟格式化，导入 `serialforge` 不修改 loguru 全局状态。
- [x] `LogFileManager` 支持显式连接会话开始/结束与落盘开关；每次连接一个 UTF-8 时间戳 `.txt` 文件；活动连接切换落盘开关继续写原文件，探测阶段不创建文件。
- [x] 默认目录使用 `QStandardPaths` 的用户本地数据目录和应用名；文件名冲突追加后缀；保留清理只删除符合本库时间戳命名的文件，最多保留 `max_files`。
- [x] 文件行符合设计格式并包含 `SPEC:<name>` / `MATCHED:<name>` / `RAW` TX 标注；`TrafficRecord` 与文件记录表达一致。
- [x] 达到 `max_file_bytes` 后停止写 TX/RX 流量，继续写 EVT，写一次超限说明并在结束时汇总丢弃行数。
- [x] 覆盖运行时切换、目录创建/不可写、冲突文件名、清理失败、文件上限和仅 DEBUG 等设计文档 T-21 测试清单；定向测试与阶段 CI 通过。
