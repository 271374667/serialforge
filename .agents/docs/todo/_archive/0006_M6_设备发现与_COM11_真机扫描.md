# 0006_M6 设备发现与 COM11 真机扫描

> 状态: 已完成  |  创建: 2026-10-08  |  完成: 2026-10-08
> 优先级: 高  |  关联 checkpoint: checkpoint/0007_M6 设备发现与 COM11 真机扫描.md

## 背景

用户提供 Windows 真机 COM11，115200 波特率，发送 `Version\r\n`，回复为无结束符的 `Software version <版本号>`。2026-10-08 实测当前版本 `1.02`，COM11 的 VID/PID 为 `067B:23A3`。M6 按设计文档第 14 节完成扫描、波特率探测、缓存与 `DeviceFinder` 后，用这台设备做显式真机验收。

## 目标（验收标准）
- [x] 实现 `PortScanner`、`BaudProber`、`BaudCache` 与 `DeviceFinder`，覆盖 `ALL`/`FIRST_MATCH`、取消、缓存回退、占用端口跳过和句柄释放。
- [x] 无硬件测试默认不打开真实串口；发现流程的关键分支由假后端验证。
- [x] 发现探测按 `profile.framing` 定界；无结束符的回复在静默间隔后也能完成探测，假后端覆盖分片回复和取消。
- [x] 用户显式运行真机测试时，用 `CommandSpec("Version", r"Software version (?P<version>\d+\.\d+)")`、发送 `Version\r\n`、115200 和可配置静默间隔帧定界扫描 COM11；得到端口、波特率及版本回复，版本号不得写死。
- [x] 完成 M6 阶段 CI 和真机验证记录，汇报后等待确认进入 M7。
