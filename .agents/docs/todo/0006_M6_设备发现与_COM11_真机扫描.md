# 0006_M6 设备发现与 COM11 真机扫描

> 状态: 排队  |  创建: 2026-10-08  |  完成: -
> 优先级: 高  |  关联 checkpoint: -

## 背景

用户提供 Windows 真机 COM11，115200 波特率，发送 `Version\r\n`，回复为无结束符的 `Software version <版本号>`。2026-10-08 实测当前版本 `1.02`，COM11 的 VID/PID 为 `067B:23A3`。M6 按设计文档第 14 节完成扫描、波特率探测、缓存与 `DeviceFinder` 后，用这台设备做显式真机验收。

## 目标（验收标准）
- [ ] 实现 `PortScanner`、`BaudProber`、`BaudCache` 与 `DeviceFinder`，覆盖 `ALL`/`FIRST_MATCH`、取消、缓存回退、占用端口跳过和句柄释放。
- [ ] 无硬件测试默认不打开真实串口；发现流程的关键分支由假后端验证。
- [ ] 用户显式运行真机测试时，用 `CommandSpec("Version", r"Software version (?P<version>\d+\.\d+)")`、115200 和静默间隔帧定界扫描 COM11；得到端口、波特率及版本回复，版本号不得写死。
- [ ] 完成 M6 阶段 CI 和真机验证记录，汇报后等待确认进入 M7。

## 阻塞 / 依赖

- 依赖 M5 完成与用户阶段确认；M4 不提前实现 discovery。
