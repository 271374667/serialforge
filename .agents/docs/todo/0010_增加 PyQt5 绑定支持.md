# 0010_增加 PyQt5 绑定支持

> 状态: 进行中  |  创建: 2026-10-10  |  完成: -
> 优先级: 高  |  关联 checkpoint: checkpoint/0012_PyQt5绑定支持.md

## 背景

用户 2026-10-10 明确要求“正式支持 PyQt5”。现状是 Qt6-only：`src/serialforge/qt_core.py`
只接受 `QT_API` 为 `pyside6`/`pyqt6`，并在检测到已加载 `PyQt5`/`PySide2` 时抛
`ImportError`。R5 阶段用户批准的是窄 Qt6 适配层，并把 Qt5 明确划出本轮范围
（见 `.agents/docs/knowledge/software/0010_QtCore双绑定适配决策.md`）。

现在把适配层从“双绑定”扩展为“三绑定”：新增 `pyqt5` 选择与 extra，同时保留对
`PySide2` 的拒绝和多绑定冲突检测。工作区另有前序会话未提交的 W1 文档站点层，
本次对 `pyproject.toml`、`uv.lock`、`.agents/ARCHITECTURE.md` 的改动需按 hunk 与 W1 分离。
